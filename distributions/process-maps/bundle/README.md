# Process maps

Documented against actual: an event log and a BPMN model compared, deviations ranked with their cases, and a model that learns from what people approve.

This folder runs the `process-maps` distribution of the [Knowledge Kernel](https://github.com/OpenReplicant/kernel) from
published images. There is nothing to clone or build.

## Start

```sh
cp .env.example .env              # 1. copy the settings
$EDITOR .env                      # 2. fill in the three secrets (how is written in the file)
podman compose up -d              # 3. start it (docker compose works the same)
```

Images are `ghcr.io/openreplicant/kernel` and `ghcr.io/openreplicant/kernel-postgres`, tag `main` (set `KK_IMAGE` and `KK_DB_IMAGE` in `.env` to pin a
release). The packages are public, so pulling needs no registry login. The first start takes a minute while the
database initialises. Check with `podman compose ps`.

## Sign in

Open http://127.0.0.1:8084/ui/ and sign in as `owner` with the password the demo printed.
To sign in without loading the demo, make the owner first (the password is printed once):

```sh
podman compose run --rm init kk person add owner --steward
podman compose run --rm init sh -c 'mkdir -p /tmp/p && kk up --distribution process-maps --no-stack --no-scan /tmp/p'
```

The second command installs this distribution's modules; the demo does it for you.

## Load the demo

```sh
podman compose run --rm init kk demo --distribution process-maps --no-stack
```

It installs this distribution's modules, loads the demo data (an order-to-cash event log, its BPMN model and a written procedure) and prints the owner's sign-in
(`owner_sign_in`). Running it again changes nothing. It sets the owner's password afresh, so use the one it prints.

## Connect an agent

```sh
podman compose run --rm init kk agent add claude-code      # prints the agent's password once
```

The agent's MCP server is `http://127.0.0.1:8084/mcp` with a bearer token (`podman compose run --rm init kk token agent_claude_code`);
the repository's docs/harness.md covers the harness side.

## Stop, reset

```sh
podman compose down        # stops; the data stays in the volumes
podman compose down -v     # stops and deletes the data
```

Ports are on 127.0.0.1 only. Generated by `kk distribution bundle process-maps`; do not put anything of yours in this
folder except `.env`, which stays out of version control.
